寻找目标域名

目标域名基础条件
不要使用跳转域名（使用跳转完成的域名）
目标网站必须支持 TLS1.3
目标网站必须支持 X25519
目标网站必须支持HTTP/2 (H2)
目标域名必须和 SNI 匹配
不使用带 CDN 的网站当目标网站

RealiTLScanner目标网站扫描工具
Windows项目地址：https://github.com/XTLS/RealiTLScanner/releases​
macOS项目地址：LiZu-KJ/RealiTLScanner Releases​
RealiTLScanner 尽量在本地运行，不要在远端
首先使用RealiTLScanner工具，扫描VPS，导出结果 file.csv 文件，命令如下：
MacOS、Linux 命令
来到桌面
cd Desktop
​
高并发扫描并把结果保存到桌面
./RealiTLScanner -addr VPSIP -port 443 -thread 100 -timeout 5 -out file.csv
​
Windows 命令(程序在桌面)
Bash
cd "%USERPROFILE%\Desktop”
​
高并发扫描并把结果保存到桌面
RealiTLScanner-windows-64.exe -addr VPSIP -port 443 -thread 100 -timeout 5 -out file.csv
​

Reality 协议目标网站检测工具

使用 Reality 协议目标网站检测工具 对之前导出的结果进行检测
首先在VPS安装reality协议目标检测工具
Linux x86_64
wget https://github.com/V2RaySSR/RealityChecker/releases/latest/download/reality-checker-linux-amd64.zip
​
Linux ARM64
wget https://github.com/V2RaySSR/RealityChecker/releases/latest/download/reality-checker-linux-arm64.zip
​
安装unzip 解压工具
apt update && apt install -y unzip
​
解压zip文件
unzip reality-checker-linux-amd64.zip
​
添加执行权限
chmod +x reality-checker
​
开始使用
./reality-checker
​
批量检测命令
./reality-checker csv file001.csv
​
SUI面板部署命令
bash <(curl -Ls https://raw.githubusercontent.com/alireza0/s-ui/master/install.sh)
​
隧道连通命令【本地操作】
ssh -L <本地端口>:127.0.0.1:<远程面板端口> <服务器用户名>@<服务器IP>
​
例如：http://127.0.0.1:10808/50000
若 SSH 用非默认端口（如 2222），加 -p 2222
ssh -fN -p 2222 -L <本地端口>:127.0.0.1:<远程面板端口> <服务器用户名>@<服务器IP>
